# Garfield admin quick start

This pilot uses sample data in an isolated staging site.

## Sign in

1. Open https://garfield-operations-staging.phil-kolevski.workers.dev/ops in your normal browser. Bookmark this address for daily use.
2. Enter the email address the owner approved for you. Enter the code from your inbox; check spam if it does not arrive. You do not need a Cloudflare account.
3. Complete MFA. For a first sign-in, follow the setup prompt to enroll your device or an authenticator application.

## Set up or manage MFA

Open https://hidden-shadow-9100.cloudflareaccess.com in the same browser. Choose **Account → Account → MFA Devices → Add an MFA device**. Choose Biometrics or Authenticator application and follow the prompts. If you already have a method enrolled, you may need to verify with it before adding another.

Return to the admin website using **Open Garfield Admin — Staging** in the launcher. If the launcher is empty, use the direct website address above. For a lost authenticator or an access-denied message, contact the owner with the error text and your sign-in email. Never send login codes, setup keys or recovery codes.

## Review a listing

1. In **My account**, confirm your email and role: **admin**.
2. Open **Approvals**. Review the direct listing, product identity, seller and evidence of delivery to Mexico.
3. Approve only when the evidence is complete. International delivery requires retailer and ship-from countries, displayed price, currency, and current delivery-evidence dates. Date fields are labeled UTC. Shipping charges may be left unknown.
4. If the evidence is incomplete, leave the item pending or reject it with a clear reason. Never invent evidence for real listings.
5. Check **Activity** for your email and decision. Approved listings appear in **Inventory**.

Sample exercises may use explicitly labeled simulated evidence. Only the owner manages users through **People & roles**.
